Reference Guide

Signal Quality Classification & Technical Disclosures

80% – 100%

Excellent

Optimal throughput, low latency. Ideal for 4K/8K UHD streaming, competitive gaming, and heavy bidirectional transfers.

65% – 79%

Very Good

Robust and stable connection. Excellent for multiple simultaneous HD video calls, VPNs, and responsive web browsing.

50% – 64%

Good

Reliable for general internet usage, email, standard video streaming, and social media with minimal buffering.

35% – 49%

Fair

Usable but vulnerable to attenuation. May experience intermittent speed drops, increased ping, or packet retransmissions.

0% – 34%

Weak

Edge of coverage. High packet loss, frequent disconnection risk, and sluggish load times. Relocation recommended.

📐
Estimated dBm Calculation & Limitations

Windows operating systems expose signal strength as a normalized integer from 0 to 100% rather than raw physical milliwatt RF power. Estimated dBm is calculated using the industry standard linear approximation: dBm ≈ (Signal% / 2) - 100. This is clearly labeled as an estimate. When your wireless driver supports native RSSI reporting (Windows 11+), the native value is displayed alongside.

🛡️
Browser Sandbox & Operating System Architecture

Standard browser JavaScript running in Chrome, Edge, or Firefox operates in a secure client-side sandbox and cannot directly inspect 802.11 radio frames or nearby access points. This application uses a Python Flask backend to securely query native Windows netsh wlan commands and stream live telemetry to the dashboard.

🌐
Physical Environmental Factors

Actual connection performance is influenced by factors beyond signal percentage: physical obstructions (concrete walls, metal partitions), 2.4 GHz vs 5 GHz channel attenuation, co-channel interference from neighboring routers, microwave ovens, Bluetooth transmitters, and adapter antenna design.
